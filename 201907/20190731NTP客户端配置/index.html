ntp客户端配置

发布于2019-07-31
Linux网络

安装

yum install ntp

修改配置

vim /etc/ntp.conf
server ntp1.aliyun.com
server ntp2.aliyun.com
server ntp3.aliyun.com
server ntp4.aliyun.com
server ntp5.aliyun.com
server ntp6.aliyun.com
server ntp7.aliyun.com

手动同步

ntpdate ntp1.aliyun.com

自动同步

systemctl restart ntpd
ntpq -p
