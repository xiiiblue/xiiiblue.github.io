R1D二级路由规则配置

参考: https://www.right.com.cn/forum/thread-4040453-1-1.html

vi /etc/config/firewall
config zone
    option name 'lan'
    option input 'ACCEPT'
    option output 'ACCEPT'
    option forward 'ACCEPT'

config zone
    option name 'wan'
    option input 'ACCEPT'
    option output 'ACCEPT'
    option forward 'ACCEPT'

config forwarding
    option src 'wan'
    option dest 'lan'
