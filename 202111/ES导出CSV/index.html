Technical note

ES导出CSV

发布于2022-11-02
Elasticsearch数据库

参考文档

  • https://cloud.tencent.com/developer/article/1639594
  • https://github.com/taraslayshchuk/es2csv/blob/master/docs/EXAMPLES.rst

Github

  • https://github.com/taraslayshchuk/es2csv

参数

  • -i 索引名
  • -q query dsl
  • -a 认证信息 格式：user: password
  • -u esurl 格式： http://ip:9200
  • -o 命名
  • -r qurey formated

示例

# 需要python2.7环境
conda  create --name py27 python=2.7
conda activate py27

# 安装es2csv
pip install es2csv

# 导出
es2csv -i policies_hydrabot -u  10.20.41.30:9200  -o dump.csv -r -q '{"_source":["title","url","collectTime","createTime"],"query": {"range": {"collectTime": {"gt": "2021-10-01 00:00:00"}}}}'
