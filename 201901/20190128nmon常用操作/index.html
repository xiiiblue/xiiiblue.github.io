nmon常用操作

发布于2019-01-28阅读

官网及下载

http://nmon.sourceforge.net/pmwiki.php

简易启动参数

./nmon  -f -t -r test -s 10 -c 30

-f ：按标准格式输出文件名称：_YYYYMMDD_HHMM.nmon
-t 输出最耗资源的进程
-s ：每隔n秒抽样一次 -c ：取出多少个抽样数量

参数详细说明

https://www.ibm.com/support/knowledgecenter/zh/ssw_aix_72/com.ibm.aix.cmds4/nmon.htm

GUI模式说明

q : 停止并退出 Nmon
h : 查看帮助
c : 查看 CPU 统计数据
m : 查看内存统计数据
d : 查看硬盘统计数据
k : 查看内核统计数据
n : 查看网络统计数据
N : 查看 NFS 统计数据
j : 查看文件系统统计数据
t : 查看高耗进程
V : 查看虚拟内存统计数据
v : 详细模式
