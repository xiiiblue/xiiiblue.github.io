CentOS7安装VirtualBox

发布于2019-03-08阅读

下载

https://www.virtualbox.org/wiki/Downloads

安装

yum install SDL-devel gcc kernel-devel
yum install ./VirtualBox-6.0-6.0.4_128413_el7-1.x86_64.rpm
vboxconfig

启动

开启X11转发

ssh -Y root@10.211.55.11
virtualbox
