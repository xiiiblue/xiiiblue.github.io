FRP部署笔记

发布于2022-11-02阅读
网络

官网

  • https://github.com/fatedier/frp/releases
  • https://gofrp.org/docs/examples/

类似应用

  • LanProxy
  • Ngrok

配置

服务端frps.ini

[common]
bind_port = 37000
token = yourtoken

客户端frpc.ini

[common]
server_addr = your_ip
server_port = 37000
token = yourtoken

[web]
type = tcp
local_ip = 127.0.0.1
local_port = 8080
remote_port = 37001

[socks5]
type = tcp
remote_port = 37002
plugin = socks5
plugin_user = yourname
plugin_passwd = yourpass

启动脚本

./frps -c frps.ini
./frpc -c frpc.ini
