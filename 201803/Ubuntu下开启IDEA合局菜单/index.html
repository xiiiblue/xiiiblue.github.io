Ubuntu下开启IntelliJ IDEA顶部全局菜单

发布于2018-11-06阅读
Linux开发工具
历史归档

本文已停止维护，内容可能过时、过于简略或仅适用于特定历史环境。保留原文是为了避免已有链接失效，请勿直接用于生产环境。

安装jayatana

sudo add-apt-repository ppa:danjaredg/jayatana
sudo apt update
sudo apt install jayatana

编辑idea64.vmoptions

vi /path/to/idea/bin/idea64.vmoptions 追加一行：

-javaagent:/usr/share/java/jayatanaag.jar

参考文档

https://intellij-support.jetbrains.com/hc/en-us/community/posts/115000060530—Ubuntu-No-global-menu-with-Jayatana
