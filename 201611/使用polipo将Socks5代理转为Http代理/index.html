使用polipo将Socks5代理转为Http代理

发布于2018-11-06阅读
网络
历史归档

本文已停止维护，内容可能过时、过于简略或仅适用于特定历史环境。保留原文是为了避免已有链接失效，请勿直接用于生产环境。

下载

https://www.irif.fr/~jch/software/polipo/polipo.html

编译安装

vi Makefile PREFIX = /home/woegoex BINDIR = $(PREFIX)/bin MANDIR = $(PREFIX)/man INFODIR = $(PREFIX)/info LOCAL_ROOT = $(PREFIX)/www DISK_CACHE_ROOT = $(PREFIX)/cache

配置

vi config socksParentProxy = “IP:PORT” socksProxyType = socks5 proxyAddress = “0.0.0.0” proxyPort = LocalPort

启动

nohup ./polipo -c config
